# Telegram-бот еженедельного отчёта ОД
### Сеть «Хачапури Марико»

---

## Что делает бот

| Время | Действие |
|---|---|
| Пятница 09:00 | Пишет РШ, КМ и маркетологу — просит статус за неделю |
| Пятница 16:00 | Забирает KPI из iiko и задачи из Bitrix24 |
| Пятница 16:00 | Пишет ОД: «Данные собраны, добавь комментарий» |
| После ответа ОД | Генерирует отчёт через ИИ, отправляет ОД на проверку |
| После подтверждения ОД | Отправляет отчёт директору по развитию |

---

## Шаг 1 — Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Придумай название: `ОД Отчёт Марико`
4. Придумай username: `mariko_od_report_bot`
5. BotFather пришлёт **токен** — сохрани его (это `TELEGRAM_TOKEN`)

---

## Шаг 2 — Узнать Telegram ID нужных людей

1. Каждый участник (ОД, директор, РШ, КМ, маркетолог) открывает бота **@userinfobot**
2. Пишет ему `/start`
3. Бот отвечает числом — это и есть Chat ID
4. Записывай: ОД → `OD_CHAT_ID`, директор → `DIRECTOR_CHAT_ID` и т.д.

---

## Шаг 3 — Получить Bitrix24 Webhook

1. Зайди в Bitrix24 → **Приложения** → **Вебхуки** → **Входящий вебхук**
2. Нажми «Добавить вебхук»
3. Выдай права: `task` (задачи)
4. Скопируй ссылку вида `https://yourcompany.bitrix24.ru/rest/1/xxxxxx/`
5. Это твой `BITRIX_WEBHOOK`
6. Свой ID пользователя в Bitrix24 — посмотри в профиле (URL: `/company/personal/user/**ID**/`)

---

## Шаг 4 — Получить данные iiko

1. Зайди в **iiko.biz** → Настройки → API
2. Логин и пароль — те же, что для входа
3. ID организации — в адресной строке при открытии ресторана, или в разделе «Рестораны»
4. Если несколько точек — перечисли ID через запятую: `uuid1,uuid2,uuid3`

---

## Шаг 5 — Получить ключ Claude API

1. Зайди на **console.anthropic.com**
2. Войди или зарегистрируйся
3. Раздел **API Keys** → **Create Key**
4. Скопируй ключ — это `ANTHROPIC_API_KEY`
5. Пополни баланс на $5 — хватит на ~200 отчётов

---

## Шаг 6 — Задеплоить на Railway

1. Зайди на **railway.app** → войди через GitHub
2. Нажми **New Project** → **Deploy from GitHub repo**
3. Загрузи папку с файлами бота (или создай репозиторий на GitHub)
4. Перейди в **Variables** и добавь все переменные из файла `.env.example`
5. Railway автоматически запустит бота

**Бесплатный тариф Railway:** 500 часов/месяц — для бота этого хватит.

---

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Инструкция |
| `/status` | Что уже собрано на эту неделю |
| `/collect` | Вручную забрать данные из iiko и Bitrix24 |
| `/generate` | Сгенерировать отчёт прямо сейчас |

## Частые вопросы

**Бот не пишет команде в 09:00**
→ Проверь, что RSH_CHAT_ID, KM_CHAT_ID, MKT_CHAT_ID заполнены правильно.
→ Каждый должен написать боту `/start` хотя бы раз — иначе Telegram блокирует отправку.

**iiko возвращает пустые данные**
→ Проверь правильность IIKO_ORG_IDS — это UUID, не название.
→ В iiko.biz → Рестораны → нажми на точку → ID в URL.

**Bitrix24 не отдаёт задачи**
→ Убедись что в вебхуке включены права на `task`.
→ BITRIX_OD_USER_ID должен совпадать с ID пользователя, чьи задачи нужны.

**Отчёт получается слишком коротким**
→ Попроси команду присылать более подробные отчёты.
→ Или добавь комментарий ОД — он сильно влияет на качество итогового текста.
